# 数学学科竞赛级难度对照表

| 领域名称 | 竞赛级难度描述 |
|---------|---------------|
| 代数-方程与不等式 | 抽象函数方程迭代解（Banach不动点定理），非线性偏微分方程形式解，Painlevé方程，混沌动力系统，分支理论，不变流形与中心流形定理 |
| 代数-多项式 | 代数曲线奇点消解，Hilbert零点定理应用，形式幂级数环，Weierstrass准备定理，超越数论中Gelfond-Schneider方法，丢番图逼近中Schmidt子空间定理 |
| 代数-不等式 | Brunn-Minkowski不等式，泛函不等式（Sobolev嵌入，Poincaré），Hölder对偶空间理论，非交换几何中的不等式，算子范数估计 |
| 代数-抽象代数 | 有限单群分类定理应用，伽罗瓦理论（尺规作图判定），表示论基础（特征标理论），同调代数入门（Ext, Tor），代数数域类域论基础，p-群结构定理，特征标计算，Murnaghan-Nakayama法则，Young置换模的分解定理（Young规则），交换代数 |
| 几何-平面几何 | 射影几何（Desargues配置、Hessian点列），复平面几何（莫比乌斯变换），几何不变理论，代数曲线相交理论（Berge公式），椭圆曲线算术，几何函数论 |
| 几何-解析几何 | 代数曲线奇点分类，平面曲线亏格与Riemann-Roch定理，椭圆函数（Weierstrass ℘函数），模曲线基础，仿射簇与射影簇，Groebner基方法 |
| 几何-立体几何 | 高维多面体组合几何（Euler-沐定理），Alexandrov几何嵌入定理，空间形式中的极小曲面，微分几何中的Gauss-Bonnet-Chern定理，三维流形拓扑基础 |
| 几何-微分几何 | Riemann几何基础（协变导数、曲率张量），测地线方程，Jacobi场与指数映射，比较定理（Toponogov），调和映照理论，Atiyah-Singer指标定理入门 |
| 数论-初等数论 | 解析数论基础（Dirichlet L函数），素数定理证明思路，筛法（Selberg筛法），大筛法，Circle Method在Goldbach问题中的应用，模形式基础 |
| 数论-丢番图方程 | Mordell-Weil定理（椭圆曲线有理点群结构），Siegel定理（整数点），Baker理论（对数线性形式），Mordell猜想（Faltings定理），abc猜想与Vojta猜想 |
| 数论-代数数论 | 类域论基础（Artin互反律），局部域理论（p-adic数），Zeta函数与解析延拓，岩泽健吉定理，Iwasawa理论，Langlands纲领入门 |
| 数论-模形式 | 模形式空间结构（Mordell-Weil, Eisenstein, cusp），Fricke群，Selberg迹公式入门，志村五郎理论，模曲线几何，Langlands对应的特例 |
| 概率论-基础概率 | 随机过程（布朗运动、Lévy过程），Itô随机积分，概率位势理论，马尔可夫随机场，随机微分方程，泛函中心极限定理 |
| 概率论-数理统计 | asymptotic统计理论（delta方法），U-统计量，经验过程理论，Nonparametrics，High-dimensional statistics（RDoC），贝叶斯asymptotic，统计学习理论（VC维） |
| 线性代数-矩阵 | 矩阵范数与算子理论，矩阵极分解与奇异值分解（Von Neumann迹不等式），矩阵扰动理论（Bergman投影），矩阵凸优化，量子信息中的矩阵理论 |
| 线性代数-高等线性代数 | 表示论基础（群表示），特征标理论，舒尔引理，Weyl特征公式，范畴论视角下的线性代数，张量范畴入门 |
| 微积分-极限与连续 | 实分析基础（Lebesgue测度，Borel集），Vitali收敛定理，Littlewood三原则，傅里叶变换（L²空间），分布理论（广义函数），Sobolev空间入门 |
| 微积分-导数与微分 | 微分几何中的联络理论，黎曼流形上的微分，Hodge分解定理，微分算子椭圆正则性，Nash嵌入定理，Sobolev嵌入定理 |
| 微积分-积分 | Lebesgue积分理论，Riesz表示定理，Fourier变换（Plancherel），Hilbert变换，积分几何（Radon变换），鞅论基础 |
| 微积分-微分方程 | 偏微分方程基础（椭圆、抛物、双曲），Sobolev空间与弱解，Green函数与基本解，算子半群理论（Hille-Yosida），Navier-Stokes方程入门，几何分析中的椭圆估计 |

| 组合数学-基础 | Enumerative combinatorics（generating functions, Lagrange inversion），组合代数几何入门，Hopf代数，组合计数中的表示论方法，连接计数与代数拓扑（Euler characteristic） |

| 组合数学-代数组合 | 组合设计理论（有限几何，差分集），编码理论基础（线性码，Golay码），代数组合学（关联方案，Terwilliger代数），极端集合论，凸多胞形组合学 |
